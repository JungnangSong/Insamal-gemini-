# 류경기체 인사말씀 AI 스킬

**요청서만 채우면 중랑구청장 인사말씀 초안이 한글 파일로 나오는 AI 스킬**

홍보담당관 「구청장 인사말씀 원고 작성 매뉴얼」(2026. 10.)과 우수사례 인사말씀, 구정 자료를 바탕으로 구청장님 말투와 구성에 맞춘 초안을 만듭니다.

> ⚠️ 결과물은 **부서 초안**입니다. 이름·숫자·사업 내용을 담당자가 확인하고, 비서실 확인을 거쳐 사용하세요.

---

## 무엇을 해 주나요?

1. 부서가 **요청서**(10칸)를 채워 AI에게 줍니다.
2. AI가 매뉴얼과 우수사례 기준으로 **인사말씀 초안**을 씁니다.
3. 클로드에서는 우수사례와 같은 표지·서식의 **한글(HWPX) 파일**까지 만들어 줍니다.

결과물에는 이런 것이 자동으로 들어갑니다.

- 첫인사 → 감사와 격려 → 행사 이야기 → 중랑구 이야기 → 끝인사 (매뉴얼 5단계)
- 실명과 이유를 붙인 감사, 숫자 중심의 내용, 구청의 지원과 앞으로의 계획
- 사람이 확인해야 할 곳은 **노란 형광펜** 표시 (`○○○`, `보완 바람`, `확인 바람`)
- 본문 함초롱바탕 15pt, 온점·쉼표 줄바꿈, 참고 박스 자동 정렬

## 폴더 안에 든 것

```
├─ SKILL.md                 스킬 본문 (규칙 + 우수사례 예시 12편) ← 핵심
├─ request_form_v3.md        부서가 채우는 요청서 양식
├─ converter.html            AI가 쓴 글을 한글 파일로 바꾸는 웹페이지 (챗GPT·제미나이용)
├─ scripts/
│   └─ make_hwpx.py         한글(HWPX) 파일을 만드는 프로그램
├─ assets/
│   └─ template_insamal.hwpx   표지·서식을 빌려 쓰는 원본 틀
└─ examples/                예시 원고(JSON)
    ├─ blank_request_form.json        빈 요청서 양식
    ├─ volunteer_day_*.json           자원봉사자의 날 (복지)
    ├─ scholarship_*.json             장학금 수여식 (교육)
    └─ merchants_meeting_*.json       상인회장 간담회 (경제)
```

| 원하는 것 | 필요한 파일 |
|---|---|
| 인사말씀 **글**만 받기 | `SKILL.md` |
| **한글 파일**까지 받기 | `SKILL.md` + `scripts/` + `assets/` (폴더 구조 그대로) |
| 요청서 양식 | `request_form_v3.md` |
| 챗GPT·제미나이 결과를 한글 파일로 | `converter.html` (따로 받아 웹브라우저로 열기) |
| 예시 참고 | `examples/` (없어도 작동함) |

## 사용법

### 1. 클로드 (Claude) — 한글 파일까지 나옴 ✅ 추천

1. 이 저장소 화면에서 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. 클로드에서 **설정 → 기능(Capabilities) → 스킬(Skills)**로 가서 받은 zip을 올립니다.
   - 올라가지 않으면 zip을 풀고, 안의 폴더(맨 위에 `SKILL.md`가 있는 폴더)를 다시 zip으로 묶어 올리세요.
3. 새 대화에서 요청서를 붙여 넣거나 첨부하고 **"인사말씀 써 줘"**라고 하면 됩니다.

> 메뉴 이름은 클로드 화면 개편에 따라 조금 다를 수 있습니다.

### 2. 챗GPT (ChatGPT) — 글로 나옴

1. **GPT 탐색 → 만들기(Create)**로 나만의 GPT를 만듭니다.
2. **지식(Knowledge)**에 `SKILL.md`와 `request_form_v3.md`를 올립니다.
3. **지침(Instructions)** 칸에 아래 [짧은 지시문](#챗gpt제미나이용-짧은-지시문)을 붙여 넣습니다.
4. 나온 원고를 [한글 파일로 바꾸기](#챗gpt제미나이-결과를-한글-파일로-바꾸기)로 HWPX를 만듭니다.

> 챗GPT 무료 이용자는 GPT를 직접 만들 수 없습니다. 만든 사람이 공유한 GPT 링크로 들어가 쓰면 됩니다.

### 3. 제미나이 (Gemini) — 글로 나옴

1. **젬(Gem) 관리자 → 새 젬**을 만듭니다.
2. 파일에 `SKILL.md`와 `request_form_v3.md`를 올립니다.
3. 지침 칸에 아래 [짧은 지시문](#챗gpt제미나이용-짧은-지시문)을 붙여 넣습니다.
4. 나온 원고를 [한글 파일로 바꾸기](#챗gpt제미나이-결과를-한글-파일로-바꾸기)로 HWPX를 만듭니다.

### 챗GPT·제미나이용 짧은 지시문

```text
너는 류경기 중랑구청장 명의 행사 인사말씀(개조식 말씀자료) 초안을 쓰는 도우미다.
반드시 첨부 파일 SKILL.md의 규칙을 모두 따른다. 우선순위는 ① 소통지원팀 매뉴얼(2026. 10.)
② 2023 공지사항 ③ 우수사례 12편이다.

1. 사용자가 요청서(request_form_v3.md 양식)를 주면 ★ 칸이 비었는지 먼저 확인하고,
   비었으면 한 번에 묶어 짧게 묻는다.
2. 구성: 첫인사·감사 → 행사 이야기 → 중랑구 이야기(현황·지원·계획) → 끝인사.
   꼭지 3~5개, ○ 하나에 한 이야기.
3. 말투: 첫 인사와 맨 끝 "감사합니다."만 경어체, 나머지는 ~임/~함/~드림/~바람/~겠음.
   "기쁘게 생각함", "감사하게 생각함", "영광" 금지. 대시(—)·굵은 글씨 금지.
4. 사실은 받은 것만 쓴다. 이름·숫자·일화를 지어내지 않는다.
   모르는 곳은 ○○○ 또는 (보완 바람)으로 남긴다.
5. 정확한 숫자와 출처는 ■ 참고 박스에, 본문에는 어림한 숫자를 쓴다.
6. 온점·쉼표 뒤에서 줄을 바꾸고, 한 호흡이 한 줄을 넘으면 두 줄로 나눈다.
7. 원고는 아래 모양으로만 출력하고, 굵은 글씨(**)·제목 기호(#)·표는 쓰지 않는다.
   (행사명) / ○ 일시 : / ○ 장소 : / ○ 참석 : / ○ 내용 : / (담당 부서)
   1. 꼭지 제목 → ○ 항목 → ■ 참고 박스 제목 → - 항목 : 내용 → … → 감사합니다.
8. 원고가 끝나면 줄을 바꿔 "---" 아래에 작성 메모(보완할 곳, 더 받으면 좋아질 재료)를 붙인다.
```

### 챗GPT·제미나이 결과를 한글 파일로 바꾸기

`converter.html`은 AI가 쓴 글을 붙여 넣으면 클로드에서 만든 것과 **똑같은 서식의 한글(HWPX) 파일**로 바꿔 주는 웹페이지입니다. 설치할 것이 없고, 원고는 내 컴퓨터 안에서만 처리되어 밖으로 나가지 않습니다.

1. 이 저장소에서 `converter.html`을 누르고, 오른쪽 위 **내려받기(Download raw file)** 버튼으로 받습니다.
2. 받은 파일을 더블클릭해 크롬·엣지·웨일 같은 웹브라우저로 엽니다. **인터넷이 없어도 됩니다**(망분리된 업무용 PC에서도 작동).
3. 챗GPT·제미나이가 쓴 원고를 1번 칸에 붙여 넣습니다.
4. 표지 칸과 미리보기의 노란 표시를 확인하고 **한글 파일 만들기**를 누릅니다.
5. 크롬·엣지에서는 저장 창이 뜨니 저장할 곳을 고르면 됩니다. 파일 이름이 `download`로 저장되면 이름 끝에 `.hwpx`를 붙여 주세요.

> 미리보기의 줄바꿈 자리는 한글 파일과 같습니다. 꼭지 제목은 "1. 첫인사"처럼 번호로, 항목은 ○로 시작해야 알아봅니다.

## 요청서 쓰는 법

`request_form_v3.md`의 10칸을 채웁니다. ★ 칸만 채워도 원고는 나옵니다.

| 칸 | 내용 |
|---|---|
| 1. 행사 ★ | 이름, 날짜·장소, 발언 시간, 발언 순서 |
| 2. 청중 ★ | 누가 몇 명, 분위기, 구청장님과의 관계 |
| 3. 고마운 분 ★ | 성함 / 직함 / **무엇이 고마운지** |
| 4. 꼭 하고 싶은 말 ★ | 숫자가 들어간 구체적인 한 줄 |
| 5. 꼭 넣을 숫자 | 1~3개 |
| 6. 지난번 건의 → 구가 한 일 | 있으면 꼭 |
| 7. 청중이 모이는 곳과 계획 | 시설, 시기·규모가 정해진 계획 |
| 8. 현장 장면이나 미담 | 한 가지 |
| 9. 하면 안 되는 말 ★ | 없으면 '없음' |
| 10. 첨부 | 계획서, 현황, 참석자 명단 등 |

**3번(감사 이유)과 6번(주민 건의 → 구의 조치)이 원고 품질을 가장 크게 좌우합니다.**

## 구정 자료 (선택)

스킬은 숫자를 다음 순서로 찾습니다.

1. 요청서와 첨부 자료
2. **구정 자료** (구정백서, 구정 기본현황, 업무계획 등)
3. 스킬 안의 숫자 창고 (2026년 9월 원고 기준, 오래될 수 있음)

구정 자료는 이 저장소에 들어 있지 않습니다. 클로드 **프로젝트**에 파일 이름을 `구정자료_기준일_내용` 형식으로 올려 두고, 그 프로젝트 안에서 스킬을 쓰면 가장 정확합니다.

## 한글 파일 직접 만들기 (개발자용)

파이썬 3이 설치된 컴퓨터에서:

```bash
python3 scripts/make_hwpx.py examples/volunteer_day_speech.json 결과.hwpx
```

- 원고 JSON 모양은 `scripts/make_hwpx.py` 맨 위 설명을 보세요.
- `Pillow`가 있으면 파일 탐색기 미리보기 그림도 새 표지로 바뀝니다(없어도 작동).

## 주의사항

- **부서 초안**입니다. 반드시 담당자 확인과 비서실 확인을 거쳐 사용하세요.
- 스킬 안의 숫자는 2026년 9월 원고 기준입니다. 최신 수치로 꼭 확인하세요.
- 특정 정치인에 대한 평가·지지 표현, 지어낸 일화는 쓰지 않도록 되어 있습니다.
- 축전, 영상 원고, '-습니다'체 낭독문(축사·추모사)은 이 스킬의 범위가 아닙니다.
